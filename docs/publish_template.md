# 社交平台发布模板

## 标题格式

```
{日期} AI速报｜{新闻条数}条新闻，1分钟看完
```

示例：`5.9 AI速报｜6条新闻，1分钟看完`

## 正文格式

```
今日AI圈速览，一句话划重点👇
{emoji} {分类}：{一句话摘要}
{emoji} {分类}：{一句话摘要}
...（每个分类只保留一条最有代表性的新闻）
#AI #科技新闻 #每日更新 #速报
```

## 规则

1. 每个分类标签只出现一次，选最有代表性的新闻
2. 每条新闻一句话摘要，简洁有力
3. 每条之间不需要空行，直接换行即可
4. 尾部固定话题标签：`#AI #科技新闻 #每日更新 #速报`（每个标签之间有空格）
5. 标题中新闻条数 = 正文中实际列出的条数
6. 日期格式：月.日（如 5.9）
7. 标题和正文必须分开填写，标题填入标题栏，正文填入正文编辑器
